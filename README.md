# 🧠 Quiz Application

A simple and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**. This project allows users to test their knowledge through multiple-choice questions with instant feedback and score calculation.

---

## 🚀 Features

* Multiple-choice quiz questions
* Real-time score calculation
* Instant answer validation
* Clean and user-friendly interface
* Responsive design for all screen sizes

---

## 🛠️ Technologies Used

* **HTML5** – structure of the application
* **CSS3** – styling and responsive layout
* **JavaScript** – quiz logic and interactivity

---

## 📂 Project Structure

```
Quiz-Application/
│── index.html
│── style.css
│── script.js
└── README.md
```

---

## 🎯 How It Works

1. User starts the quiz
2. Questions are displayed one by one
3. User selects an answer
4. Score is updated instantly
5. Final score is shown at the end of the quiz
